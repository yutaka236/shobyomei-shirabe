# 傷病名調べ

傷病名・症状名・ICD-10コードを入力すると、ICD-10（2013年版）の大分類（章）・中分類・小分類（3桁）を表示するスマホ向けWebアプリです。

- 収録: 22章 / 225中分類 / 1,703小分類（3桁）。4桁の細分類は未収録。外因（V〜Y章）は代表的な3桁のみ。
- 通信なしで動作（初回表示後はオフライン可）。
- 実務の診断・コーディングには、厚生労働省または公式の分類表で必ず確認してください。

## iPhoneのホーム画面に追加
1. Safariで公開URLを開く
2. 共有ボタン → 「ホーム画面に追加」

## 公開（GitHub Pages）
Settings → Pages → Branch を `main` / `(root)` に設定。

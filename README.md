# 傷病名調べ

傷病名・症状名・ICD-10コードを入力すると、ICD-10（2013年版）の大分類（章）・中分類・小分類（3桁）を表示するスマホ向けWebアプリです。

- 収録: 厚生労働省「疾病、傷害及び死因の統計分類（基本分類表）ICD-10（2013年版）準拠」の全項目。22章（大分類）/ 273中分類 / 2,092小分類（3桁）/ 13,204細分類（4桁・5桁）。
- 通信なしで動作（初回表示後はオフライン可）。
- データ出典: 厚生労働省 基本分類表（kihon2013.xlsx）。
- 実務の診断・コーディングには、厚生労働省または公式の分類表で必ず確認してください。

## iPhoneのホーム画面に追加
1. Safariで公開URLを開く
2. 共有ボタン → 「ホーム画面に追加」

## 公開（GitHub Pages）
Settings → Pages → Branch を `main` / `(root)` に設定。
